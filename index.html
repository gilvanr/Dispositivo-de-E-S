🖥️ Módulos de Entrada/Saída (E/S)

Arquitetura de Computadores — O papel essencial da comunicação com periféricos

📌 17) Principal função de um Módulo de E/S

Um módulo de E/S atua como intermediário entre o barramento do sistema (CPU + memória) e os dispositivos periféricos. Sua principal função é gerenciar a transferência de dados, resolvendo diferenças de velocidade, formato e sincronismo.

🖱️ Exemplo: Quando você digita no teclado, o módulo de E/S (controlador do teclado) recebe o código da tecla, armazena em um registrador e depois avisa a CPU via interrupção.
➡️ Resumo: Possibilitar comunicação confiável entre CPU/memória e dispositivos externos.

⚠️ 18) Por que não conectar dispositivos diretamente no barramento?

  • 1. Diversidade de sinais e temporização: Dispositivos como mouse, impressora, HD operam com tensões, velocidades e protocolos totalmente diferentes. O barramento do sistema é padronizado para alta velocidade e comunicação paralela com CPU/memória.
  • 2. Grande diferença de velocidade: A CPU trabalha em GHz, enquanto teclados, sensores ou impressoras são extremamente lentos (ms). Conectar diretamente causaria bloqueios constantes da CPU, reduzindo drasticamente o desempenho.
🔌 Analogia: Imagine conectar uma mangueira de jardim diretamente no cano principal de alta pressão de uma hidrelétrica. O módulo de E/S funciona como um "adaptador" e "válvula" que controla o fluxo e a compatibilidade.

⚙️ 19) Três funções dos Módulos de E/S

  1. Controle e temporização: Coordena o fluxo de dados entre o barramento do sistema e o dispositivo, respeitando os tempos de cada lado.
  2. Comunicação com a CPU: Através de comandos (leitura, escrita, reset) e troca de status (pronto/ocupado) usando registradores de controle/estado.
  3. Detecção de erros: Verifica erros de transmissão (paridade, CRC) e informa a CPU para tomar ações corretivas.
📀 Exemplo prático: Controladora de disco rígido (SATA/NVMe). Ela temporiza a leitura dos setores, avisa a CPU quando o dado está pronto e detecta setores defeituosos.

🔧 20) Componentes internos do Módulo de E/S

✅ 1. Registradores de dados: Armazenam temporariamente os dados que trafegam entre o dispositivo externo e o barramento do sistema. Funcionam como um buffer pequeno para sincronização.

✅ 2. Registradores de estado/controle: Contêm bits de status (ex: "pronto", "ocupado", "erro") e bits de controle (ex: "reset", "habilita interrupção"). A CPU lê esses registradores para saber se o módulo pode enviar/receber dados.

🧩 Exemplo didático: Em um mouse USB, o registrador de dados guarda o movimento (delta X/Y). O registrador de estado indica se há novo dado disponível. A CPU lê o estado, depois os dados.

🚦 Motivo 1: Diferença elétrica/temporização

Barramento PCIe opera a 16 GT/s (transações por segundo), enquanto um mouse PS/2 opera a 10-20 kHz. Módulo de E/S faz a "tradução" de protocolos.

⏱️ Motivo 2: Bloqueio de desempenho

Se a CPU esperasse uma impressora para cada caractere, o sistema travaria. O módulo de E/S realiza buffering e interrupções.

🔁 Funções extras relevantes

Além das 3 citadas: decodificação de endereços, formatação de dados (serial/parallel) e gerenciamento de interrupções.
